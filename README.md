# animewing
Watch anime with Japanese subtitles.

## Features
- No ads
- Japanese subtitles
- Color coded words based on adjective, noun, verb, connecting words
- Jump to previous/next dialogue
- Anime watch progress is saved and restored
- Watch together: video players synced over websockets

## Bring your own dictionary
This website does not feature a built-in dictionary. You are free to use any dictionary or translation tools you like.  

We render the subtitle text directly to the web page to make it accessible to a variety of translation tools:
- browser extensions eg. 10ten, yomitan
- built-in operating system tools eg. select text > right click > translate selection
- OCR tools
